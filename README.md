# 정보쇼츠 (yscominformation)

매일 17:07(한국 시간)에 GitHub 서버가 세로 쇼츠 1편을 자동으로 만들어 보관함에 올립니다.

- 보관함(아이폰): https://yunsub2002.github.io/yscominformation/
- 순서: 오늘의 시황 → 종목 분석 → 생활 꿀팁 (장이 쉬는 날은 시황을 건너뜀)
- `queue/` 폴더에 대본(.json)을 올리면 그 대본을 먼저, 바로 만듭니다 (정치 브리핑 등 채팅에서 만든 대본).
- 시황·종목 분석은 네이버 증권·업비트의 숫자로만 만들며, 투자 권유를 하지 않습니다.
